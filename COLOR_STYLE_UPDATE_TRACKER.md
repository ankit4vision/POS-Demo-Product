## Update Guidelines

### Elements to Update:
1. **Card Headers**: Use `#3B721A` (dark green) background with white text
2. **Primary Buttons**: Use `#3B721A` background with white text
3. **Secondary Buttons**: Use `#A7E06B` (light green) background with `#3B721A` text
4. **Accent Elements**: Use `#FDD940` (yellow) for special highlights
5. **Card Backgrounds**: Use light green gradients (`#e8f5e8` to `#a7e06b`) or yellow gradients (`#fff8e6` to `#fdd940`)
6. **Icons**: Use `#3B721A` for primary icons, `#A7E06B` for accents
7. **Badges**: Use green gradients matching the theme
8. **Borders**: Use `rgba(59, 114, 26, 0.2)` for subtle borders
9. **Shadows**: Use green-tinted shadows `rgba(59, 114, 26, 0.2)`

### Color Usage Pattern:
- **Green Cards**: Sales, Expenses, Customers, Low Stock, Reports
- **Yellow Cards**: Purchases, Products, Warnings
- **Headers**: Always dark green (`#3B721A`) with white text
- **Buttons**: Primary = dark green, Secondary = light green, Outline = green border
